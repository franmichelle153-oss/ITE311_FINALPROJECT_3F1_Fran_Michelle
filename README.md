# ChoreoBook

**Student Name:** Michelle Fran
**Course and Section:** Web System and Technologies 2 - 3F1

## Project Description
ChoreoBook: A Web-Based Choreographer Hiring System for Different Dance Genres. The system allows clients to browse, search, and hire choreographers based on their dance genre, while choreographers can manage their profiles and bookings through a content management system (CMS).

## Technologies Used
- HTML, CSS, JavaScript
- Laravel (PHP Framework)
- CMS
- MySQL
- Git and GitHub
